## 🔐 Как работает аутентификация:

### Login:
1. Вводите email и password
2. Backend возвращает `accessToken` и `refreshToken`
3. Токены сохраняются в `localStorage`
4. Перенаправление на Dashboard

### Защита маршрутов:
- Если нет токена → редирект на `/login`
- Если токен есть → доступ к приложению

### Автоматическая подстановка токена:
- Все API запросы автоматически получают заголовок:
  ```
  Authorization: Bearer YOUR_ACCESS_TOKEN
  ```

### Logout:
- Нажмите кнопку **"Logout"** в сайдбаре
- `localStorage` очищается
- Редирект на `/login`

## 🐛 Если что-то не работает:

### 1. Проверьте токен в localStorage:
```javascript
// В консоли браузера (F12)
localStorage.getItem('accessToken')
```

### 2. Проверьте Network tab (F12):
- Есть ли заголовок `Authorization: Bearer ...`?
- Какой статус ответа (200, 401, 500)?

### 3. Очистите localStorage:
```javascript
localStorage.clear()
window.location.reload()
```

### 4. Перезапустите Frontend:
```bash
# Ctrl+C
npm run dev
```
