8083 - Task Service

5433 - PostgreSQL (sprint_db)
5434 - PostgreSQL (task_db)

==========================================
Основные endpoints:
==========================================

Teams:
  GET    /api/teams
  GET    /api/teams/{id}
  POST   /api/teams
  PUT    /api/teams/{id}
  DELETE /api/teams/{id}

Users:
  GET    /api/users
  GET    /api/users/{id}
  GET    /api/users/team/{teamId}
  POST   /api/users
  PUT    /api/users/{id}
  DELETE /api/users/{id}

Sprints:
  GET    /api/sprints
  GET    /api/sprints/{id}
  GET    /api/sprints/team/{teamId}
  GET    /api/sprints/status/{status}
  POST   /api/sprints
  PUT    /api/sprints/{id}
  PATCH  /api/sprints/{id}/submit
  PATCH  /api/sprints/{id}/approve
  PATCH  /api/sprints/{id}/reject
  DELETE /api/sprints/{id}

Tasks:
  GET    /api/tasks
  GET    /api/tasks/{id}
  GET    /api/tasks/sprint/{sprintId}
  GET    /api/tasks/status/{status}
  GET    /api/tasks/assigned/{userId}
  POST   /api/tasks
  PUT    /api/tasks/{id}
  PATCH  /api/tasks/{id}/submit
  PATCH  /api/tasks/{id}/approve
  PATCH  /api/tasks/{id}/reject
  DELETE /api/tasks/{id}

Artifacts:
  GET    /api/artifacts/task/{taskId}
  GET    /api/artifacts/{id}
  POST   /api/artifacts
  DELETE /api/artifacts/{id}

Comments:
  GET    /api/comments/task/{taskId}
  GET    /api/comments/{id}
  POST   /api/comments
  PUT    /api/comments/{id}
  DELETE /api/comments/{id}
