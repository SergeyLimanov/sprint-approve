# 📊 Инструкция по использованию презентации

## Открытие презентации

1. **Откройте файл `presentation.html` в браузере:**
   - Двойной клик по файлу, или
   - Правой кнопкой → Открыть с помощью → Браузер (Chrome, Firefox, Edge)

2. **Презентация откроется в полноэкранном режиме**

## Управление презентацией

### Навигация:
- **Стрелки ← →** или **клик мышью** - переход между слайдами
- **Пробел** - следующий слайд
- **Home** - первый слайд
- **End** - последний слайд
- **ESC** - обзор всех слайдов (grid view)
- **F** - полноэкранный режим

### Номера слайдов:
- В правом нижнем углу отображается номер текущего слайда

## Структура презентации (7 слайдов)

1. **Титульный слайд** - название проекта и автор
2. **Цели проекта** - задачи и назначение системы
3. **Используемые технологии** - Backend, Frontend, БД, Infrastructure
4. **Архитектура** - схема микросервисов и их взаимодействия
5. **Что получилось** - реализованный функционал
6. **Схемы баз данных** - структура всех 4 БД с связями
7. **Выводы** - итоги и достижения проекта

## Особенности

- ✅ **Адаптивный дизайн** - работает на любом экране
- ✅ **Темная тема** - приятная для глаз
- ✅ **ASCII диаграммы** - наглядная визуализация архитектуры
- ✅ **Подсветка ключевых моментов** - зеленым цветом
- ✅ **Прогресс-бар** - внизу экрана

## Экспорт в PDF (опционально)

Если нужна PDF версия:

1. Откройте презентацию в Chrome
2. Добавьте `?print-pdf` к URL (например: `file:///path/to/presentation.html?print-pdf`)
3. Ctrl+P (Печать)
4. Выберите "Сохранить как PDF"
5. Настройки:
   - Ориентация: Альбомная
   - Поля: Нет
   - Фон: Включить

## Редактирование

Файл `presentation.html` можно редактировать в любом текстовом редакторе:
- Изменить содержимое слайдов
- Добавить новые слайды (скопировать блок `<section>...</section>`)
- Изменить тему (в строке с `theme/black.css` заменить на `white.css`, `league.css` и т.д.)

## Технологии презентации

- **Reveal.js 4.5.0** - фреймворк для HTML презентаций
- **Чистый HTML/CSS** - без зависимостей от Node.js или сборщиков
- **CDN** - все библиотеки загружаются из интернета (нужно подключение при первом открытии)
