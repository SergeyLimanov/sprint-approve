# Функционал загрузки файлов

## Что добавлено

✅ **Drag & Drop загрузка файлов** - перетащите файл в зону загрузки  
✅ **Превью для картинок** - миниатюры изображений отображаются рядом с названием  
✅ **Автоматическое сохранение** - файлы сохраняются на сервере  
✅ **Поддержка разных типов файлов** - изображения, PDF, документы  
✅ **Информация о файле** - размер, тип, автор загрузки  

## Изменения в бэкенде

### Новые файлы

1. **FileStorageProperties.java** - конфигурация хранилища файлов
2. **FileStorageService.java** - сервис для работы с файлами

### Обновленные файлы

1. **ArtifactController.java**
   - `POST /api/artifacts/upload` - загрузка файла
   - `GET /api/artifacts/files/{fileName}` - просмотр/скачивание файла

2. **ArtifactService.java**
   - Автоматическое удаление физических файлов при удалении артефакта

### Хранилище файлов

Файлы сохраняются в папке `uploads/` в корне проекта task-service.

## Изменения во фронтенде

### Обновленные файлы

1. **api/client.ts**
   - Добавлен метод `artifactsApi.upload(formData)`

2. **pages/TaskDetail.tsx**
   - Drag & Drop зона для загрузки файлов
   - Превью для изображений (64x64px)
   - Отображение размера файла
   - Индикатор загрузки

## Как использовать

### Загрузка файла

**Способ 1: Drag & Drop**
1. Откройте страницу задачи
2. Перетащите файл в зону "Перетащите файл сюда..."
3. Файл автоматически загрузится и появится в списке артефактов

**Способ 2: Выбор файла**
1. Нажмите на зону загрузки
2. Выберите файл в диалоге
3. Файл загрузится автоматически

**Способ 3: Ссылка на внешний файл** (как раньше)
1. Нажмите "Добавить"
2. Заполните форму с URL
3. Сохраните

### Просмотр файлов

- **Картинки** - отображаются с превью, клик открывает в полном размере
- **Другие файлы** - клик скачивает файл

### Комментирование файлов

Как и раньше - нажмите на счетчик комментариев рядом с файлом.

## Поддерживаемые форматы

- **Изображения**: JPG, PNG, GIF, WebP, SVG
- **Документы**: PDF, DOC, DOCX, TXT
- **Другие**: любые файлы (без ограничений)

## Технические детали

### API Endpoints

```
POST /api/artifacts/upload
- Параметры: file (multipart), taskId, uploadedBy
- Возвращает: ArtifactDto с URL файла

GET /api/artifacts/files/{fileName}
- Возвращает файл с правильным Content-Type
- Поддерживает inline просмотр для изображений
```

### Структура хранения

```
task-service/
└── uploads/
    ├── 123e4567-e89b-12d3-a456-426614174000.jpg
    ├── 987fcdeb-51a2-43f7-9c8d-1234567890ab.pdf
    └── ...
```

Имена файлов генерируются как UUID + расширение оригинального файла.

### Безопасность

- ✅ Валидация имен файлов (защита от path traversal)
- ✅ Уникальные имена (UUID) предотвращают конфликты
- ✅ Автоматическое удаление при удалении артефакта

## Примеры использования

### Загрузка скриншота бага
1. Тестировщик находит баг
2. Делает скриншот
3. Перетаскивает в задачу
4. Комментирует: "Кнопка не работает на этом экране"

### Загрузка дизайн-макета
1. Дизайнер создает макет
2. Экспортирует как PNG
3. Загружает в задачу
4. Команда видит превью и может обсудить

### Загрузка документации
1. Аналитик пишет спецификацию в PDF
2. Загружает в задачу
3. Разработчики скачивают и изучают

## Ограничения

- Максимальный размер файла: зависит от настроек Spring Boot (по умолчанию 1MB)
- Для увеличения лимита добавьте в `application.yml`:

```yaml
spring:
  servlet:
    multipart:
      max-file-size: 10MB
      max-request-size: 10MB
```
